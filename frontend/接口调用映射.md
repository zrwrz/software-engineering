# borrow-planet-prototype 接口调用映射

本文档用于说明：`前后端接口文档.md` 中每个接口，在当前前端代码里的实际调用位置。

> 统计范围：`src/views/*.vue` 中的业务调用（通过 `src/api/index.js` 统一发起）。

## 4. 认证与用户接口

- `POST /auth/register`（4.1 用户注册）
  - 已接入：`src/views/RegisterView.vue` -> `submit()` -> `authApi.register()`
- `POST /auth/login`（4.2 用户登录）
  - 已接入：`src/views/LoginView.vue` -> `submitUserAccount()`、`submitAdmin()` -> `authApi.login()`
- `GET /users/me`（4.3 获取当前用户信息）
  - 已接入：`src/views/DashboardView.vue` -> `loadDashboard()` -> `userApi.me()`
- `PUT /users/me`（4.4 修改个人资料）
  - 已接入：`src/views/DashboardView.vue` -> `saveProfile()` -> `userApi.updateProfile()`
- `PUT /users/me/password`（4.5 修改密码）
  - 已接入：`src/views/DashboardView.vue` -> `savePassword()` -> `userApi.changePassword()`

## 5. 物品平台接口

- `GET /items`（5.1 物品列表）
  - 已接入：`src/views/ItemsView.vue` -> `loadItems()` -> `itemApi.list()`
- `GET /items/{itemId}`（5.2 物品详情）
  - 已接入：`src/views/ItemsView.vue` -> `openDetail()` -> `itemApi.detail()`
- `POST /items/submissions`（5.3 提交物品上传申请，用户）
  - 已接入：`src/views/ItemsView.vue` -> `submitItemUpload()` -> `itemApi.submitSubmission()`（`DEMO_MODE` 下回退本地队列）
- `GET /admin/items/submissions`（5.4 查询物品上传审核队列，管理员）
  - 已接入：`src/views/ItemReviewView.vue` -> `loadQueue()` -> `itemApi.adminSubmissionList()`（`DEMO_MODE` 下回退本地队列）
- `PATCH /admin/items/submissions/{submissionId}/audit`（5.5 审核物品上传申请，管理员）
  - 已接入：`src/views/ItemReviewView.vue` -> `approveSubmission()` / `rejectSubmission()` -> `itemApi.auditSubmission()`（`DEMO_MODE` 下回退本地审核流转）
- `PUT /items/{itemId}`（5.6 编辑物品，管理员）
  - 已接入：`src/views/ItemsView.vue` -> `saveAdminItem()` -> `itemApi.update()`
- `PATCH /items/{itemId}/status`（5.7 上下架，管理员）
  - 已接入：`src/views/ItemsView.vue` -> `toggleItemStatus()` -> `itemApi.setStatus()`

## 6. 预约借还接口

- `POST /orders/reservations`（6.1 创建预约）
  - 已接入：`src/views/ItemsView.vue` -> `submitReserve()` -> `orderApi.createReservation()`
- `GET /orders/my`（6.2 我的预约/订单列表）
  - 已接入：`src/views/DashboardView.vue` -> `loadDashboard()` -> `orderApi.my()`
- `GET /orders`（6.2A 订单列表，管理员）
  - 已接入：`src/views/DashboardView.vue` -> `loadDashboard()`（管理员）-> `orderApi.list()`
- `GET /orders/{orderId}`（6.3 订单详情）
  - 已接入：`src/views/DashboardView.vue` -> `handleOrderAction()`（不可直接流转状态时）-> `orderApi.detail()`
- `PATCH /orders/{orderId}/cancel`（6.4 取消预约）
  - 已接入：`src/views/DashboardView.vue` -> `handleOrderAction()`（用户 `CREATED`）-> `orderApi.cancel()`
- `PATCH /orders/{orderId}/audit`（6.5 审核预约）
  - 已接入：`src/views/DashboardView.vue` -> `handleOrderAction()`（管理员 `CREATED`）-> `orderApi.audit()`
- `PATCH /orders/{orderId}/borrow`（6.6 办理借出）
  - 已接入：`src/views/DashboardView.vue` -> `handleOrderAction()`（管理员 `APPROVED`）-> `orderApi.borrow()`
- `PATCH /orders/{orderId}/return`（6.7 办理归还）
  - 已接入：`src/views/DashboardView.vue` -> `handleOrderAction()`（管理员 `BORROWED`）-> `orderApi.return()`
- `POST /internal/orders/mark-overdue`（6.8 内部定时任务）
  - 前端不应调用（服务端内部任务接口）

## 7. 信用与统计接口

- `POST /compensations`（7.4 新增赔偿记录）

- `PATCH /compensations/{id}/status`（7.5 更新赔偿状态）
  - 已接入：`src/views/DashboardView.vue` -> `updateCompStatus()` -> `compensationApi.setStatus()`
- `GET /stats/dashboard`（7.6 统计看板）
  - 已接入：`src/views/DashboardView.vue` -> `loadDashboard()`（管理员）-> `statsApi.dashboard()`
